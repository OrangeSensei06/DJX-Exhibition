# Chapter 3 gate

`gate-v2.html` is the supplied Gate to the Jali V2 reference. The build uses its
matching arch dimensions, split double-door hinges, passage alignment and camera
trajectory. The three `*-v2.png` files are the supplied transparent artwork.

The original jali and sunset textures are identical in both supplied HTML files.
The integration retains the clipped sunset, existing text, shorter entry timing,
Setup commands, waiting state and fold-out/retrieval flow. `original.html` and the
older artwork remain as source backups.
